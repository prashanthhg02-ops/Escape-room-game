# The Last Light

A small, self-contained escape-room game that runs in your web browser. No installation or build step is required.

## Play

1. Open `index.html` in a modern web browser.
2. Click the objects in the observatory to inspect and search them.
3. Inspect the star chart behind the painting and note its three-number clue.
4. Search the desk and enter the code from the clue.
5. Take the brass key to the observatory door to escape.

Use **I could use a hint** if you get stuck. The timer tracks your time in the room; use **↺** to restart. Press **Escape** or click outside a dialog to close it.

## Project

- `index.html` — game scene, styling, puzzles, inventory, hints, and timer.

The game uses plain HTML, CSS, and JavaScript. It has no dependencies or build tools.
